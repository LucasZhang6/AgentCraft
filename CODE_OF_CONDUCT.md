# Community Code of Conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

We want this project to be a thoughtful and welcoming open-source community
where different technical judgments can be discussed through evidence.

Participants should respect one another, critique ideas rather than people,
welcome questions, acknowledge corrections, cite the work of others, and be
honest about model capability, experimental evidence, and project maturity.

Harassment, discrimination, privacy violations, impersonation, fabricated
results, or the deliberate distribution of harmful code are not acceptable.
Maintainers may remove inappropriate content and restrict participation when a
person repeatedly disrupts the community.
