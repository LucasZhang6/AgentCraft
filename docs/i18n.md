# Documentation Languages

[English](i18n.md) | [简体中文](i18n.zh-CN.md)

English is the canonical and default language for project documentation and the
interactive research site. Simplified Chinese is maintained as a first-class
translation.

## File Convention

```text
README.md             canonical English
README.zh-CN.md       Simplified Chinese
docs/topic.md         canonical English
docs/topic.zh-CN.md   Simplified Chinese
```

Each pair must link to both languages at the top. A user-facing change to
commands, defaults, behavior, API state, security boundaries, or implementation
status should update both files in the same pull request.

## Site Convention

The site resolves language in this order:

1. an explicit `?lang=en` or `?lang=zh-CN` query
2. the last language selected in local browser storage
3. English

It intentionally does not switch automatically from browser language, so links
and screenshots have a stable English default. The language control updates the
document language and preserves the current hash route.

## Source-Language Corpora

Mirrors of external documents keep the original source language and formatting
to preserve evidence. They still receive an English default index document that
describes the artifact and links to the full source-language mirror. Legal files
and vendored third-party notices are not translated because translation could
change their legal meaning.

## Review Checklist

- claims, numbers, citations, and limits match between languages
- the English file is the unsuffixed canonical path
- both files have reciprocal links
- local links resolve from each locale file
- site UI and content exist in both locale datasets
- `npm run docs:locales` and `npm test` pass
