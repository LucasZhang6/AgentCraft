# Feishu Agent Papers and Projects Corpus

[English](feishu-agent-papers-and-projects.md) | [简体中文原文镜像](feishu-agent-papers-and-projects.zh-CN.md)

This artifact is a versioned Markdown mirror of the public Feishu page
"Agent papers collection: 355 papers and 821 projects." The source document is
written primarily in Chinese, so the complete mirror preserves that language,
ordering, URLs, and line breaks rather than replacing the evidence with a
machine translation.

- [Open the complete source-language mirror](feishu-agent-papers-and-projects.zh-CN.md)
- The original Feishu page is a private research source and is not disclosed in the public repository.
- [Browse the bilingual curated research map](../README.md#research-map)
- [Browse the deduplicated URL index](../feishu_agent_urls.md)

The curated paper reviews in this project are independently written and are not
a translation of the Feishu page. Use the original-language mirror when
checking collection membership, ordering, wording, and source URLs.
