# 文档语言约定

[English](i18n.md) | [简体中文](i18n.zh-CN.md)

项目文档和交互式研究站点默认使用英语，简体中文作为一等翻译版本持续维护。

## 文件规则

```text
README.md             默认英语
README.zh-CN.md       简体中文
docs/topic.md         默认英语
docs/topic.zh-CN.md   简体中文
```

每组文档顶部必须互相链接。命令、默认值、行为、API 状态、安全边界或实现状态发生用户可见变化时，同一个 Pull Request 必须更新两种语言。

## 站点规则

站点按以下顺序决定语言：显式 `?lang=en` 或 `?lang=zh-CN`、浏览器本地保存的上次选择、英语默认值。项目不会根据浏览器语言自动改变默认值，以便共享链接和回归截图具有稳定英语基线。切换语言时保持当前 Hash 路由不变。

## 源语言语料

外部文档镜像保留原始语言和格式，以免损害证据。对应的默认英语文档会解释语料来源、内容并链接到完整源语言镜像。许可证和第三方 Notice 不翻译，以免改变法律含义。

## 检查

- 两种语言的事实、数字、引用和局限一致
- 无后缀路径为英语主文档
- 两份文件顶部双向链接
- 两种语言中的本地链接均有效
- 站点 UI 和数据都有两种语言
- `npm run docs:locales` 与 `npm test` 通过
